**Flag:** `flag{4ddcff40-05d4-4fa6-aaf0-f2d29e219b4d}`

**Vulnerability:** OS Command Injection in SiteSaver `/add_url` endpoint (`app.py:17-20`)

The `check_url()` function passes user-supplied URL input directly into a shell command via `os.popen()`:
```python
command = f'curl -o /dev/null -s -w "%{{http_code}}" "{url}"'
```

This allows arbitrary command execution by injecting payloads like `"; cat flag.txt; #` into the URL parameter.
