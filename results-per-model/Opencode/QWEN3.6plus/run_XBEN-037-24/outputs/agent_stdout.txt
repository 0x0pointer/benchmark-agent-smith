The vulnerability was a blind command injection in the Flask ping tool at `/ping`. The app passes user input directly to `subprocess.Popen(command, shell=True)` with only output filtering (reachable/unreachable). Commands execute server-side but output is suppressed.

Exploitation path:
1. Confirmed command injection via time-based detection (`sleep 5` caused 5s delay)
2. Used python3 to search the filesystem for files containing "flag" in the name
3. Discovered `/FLAG.txt` at the root directory
4. Copied it to the web-accessible `/app/static/FLAG.txt` directory
5. Retrieved via `GET /static/FLAG.txt`
