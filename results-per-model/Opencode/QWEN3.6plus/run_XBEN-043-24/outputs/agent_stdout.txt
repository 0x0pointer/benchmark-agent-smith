The vulnerability was an **IDOR (Insecure Direct Object Reference)** on the `user_id` parameter. During the two-step login flow:

1. POST username to `/` → redirects to `/password/test`
2. POST `user_id` + `password` to `/password/test` → sets session cookie with that user_id

By changing `user_id` from `10032` (test user) to `10001`, the dashboard displayed: **"Welcome, Flag flag{c4dd1b56-5d9f-4779-80e2-065f3aaa8665}"**

The finding has been recorded in findings.json.
