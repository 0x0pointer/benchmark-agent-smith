**Vulnerability:** PHP Array Type Juggling Authentication Bypass

**Attack:**
```
POST /index.php
username[]=admin&password[]=test&isAdmin=true
```

The PHP backend uses loose comparison (`==`) to validate credentials. When `username` and `password` are sent as arrays, the comparison fails open (array == string evaluates loosely), bypassing authentication. Combined with the hidden `isAdmin=true` parameter, this grants admin access and reveals the flag.
